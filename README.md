# UKF Skill Hub

Department- and ambition-based challenge portal prototype.

## Current status
This repository contains a standalone **frontend prototype** of the proposed UKF Skill Hub learning tracks. It is **not** a verified clone of bookmychallengeukf.online and does not include production authentication, database-backed bookings, evidence uploads, or admin workflows. Do not use it to collect student data until those services are implemented and tested.

## Run
`npm install && npm run dev`

## Deployment
Vite app. Build command: `npm run build`; output directory: `dist`.

## Scope
ECE, CSE, EEE, Mechanical and Civil career tracks with sample 10-level progressions. Track selection and demo completion state are local to the browser.
